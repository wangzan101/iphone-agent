# Draft skill bundle / 技能样例

A minimal, human-authored example for **reading the iOS version in Settings**.

- [APP.md](knowledge/apps/settings/APP.md) describes the app.
- [SKILL.md](skills/read-ios-version/SKILL.md) describes the task.

The visible labels assume Simplified Chinese. Both files are `draft`; they contain no claimed run history and are not automatically loaded from this examples directory.

这是一份格式样例，不是真机验收记录。它说明 App 知识与任务技能如何分开，以及怎样写前提、停止条件和结果验证。

Read [the sharing guide](../../docs/sharing.md) before adapting or contributing it. Review existing destination files before placing a copy in active `knowledge/apps/` and `skills/` paths. A parser-valid draft is not automatically a routable or verified skill.
